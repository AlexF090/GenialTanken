# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/AlexF090/GenialTanken/security/advisories/new) (Security → Report a vulnerability).

Include the affected part (web app, Cloudflare Worker or API), steps to reproduce and the impact you expect.

## Supported versions

Only the latest release, deployed at https://genialtanken.alexf090.workers.dev, receives security fixes.
